# NOTICE

Grit is original Kotlin/Compose code. It is not a copy of openGym.

openGym (https://github.com/DuarteSantos8/openGym) is AGPL-3.0 software with
separately licensed exercise media (Gym Visual). That media is **not** used here.
Grit reimplements a subset of capabilities — set shapes, named progression
ladders, estimated 1RM formulas, a muscle recovery snapshot, a training heatmap,
structural-balance heuristics, rest-timer notifications, and CSV import — against
Grit's own models, v4 catalog, pound logging, and Health Connect pipeline.

Public training formulas (Epley, Brzycki, and similar 1RM estimators; well-known
close-grip-bench structural ratios) are used as published mathematics, not as
copied tables or source.

If you need openGym itself, use that project under its AGPL terms.
